Dracula themed syntax highlighting for Jetbrains IDEs.

<!--more-->

## Installation

1. Create a folder called colors inside `C:/Users/<username>/.<JetbrainsIDE>/config/`  
> Example: `C:/Users/CLDN/.Rider2019.1/config/color/`

2.  Download and extact the [Dracula Theme](https://github.com/cameronldn/jetbrains-theme-dracula/archive/master.zip)

3. Copy the `Dracula.icls` file to the `C:/Users/<username>/.<JetbrainsIDE>/config/colors/` directory on your local machine.


Source Repository: [https://github.com/cameronldn/jetbrains-theme-dracula](https://github.com/cameronldn/jetbrains-theme-dracula)
