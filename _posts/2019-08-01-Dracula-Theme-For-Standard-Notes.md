Dracula theme, with syntax highlighting in code and markdown editors, for Standard Notes. 

<!--more-->

## Installation

1. Open the Standard Notes Web or Desktop App

2. In the Extensions menu, click `Import Extension` and paste: `https://listed.standardnotes.org/Uq5C8jZbAZ`

3. Click `Install`

4. Activate the theme!

Source Repository: [https://github.com/cameronldn/sn-theme-dracula](https://github.com/cameronldn/sn-theme-dracula)
